## Хэсэг A — Category-Partition

### A1. Сонголт ба төлөөлөх утгууд

Тестийн загварыг `POST /transfer` шилжүүлгийн функцийн тодорхойлолтод үндэслэн боловсруулав.

| Параметр | Сонголт | Төлөөлөх утгууд |
|---|---|---|
| From | Дансны төлөв | Valid, Frozen, Missing |
| To | Хүлээн авагчийн төлөв | Valid, Missing, SameAsFrom |
| Amount | Шилжүүлгийн дүн | Normal, Zero, OverBalance, OverLimit |
| Currency | Валютын хамаарал | Same, Different |

**Далд орчны сонголтууд:** дансны үлдэгдэл, өдрийн лимитийн үлдсэн хэмжээ, данс тус бүрийн валют, мөн данс царцаагдсан эсэх. Эдгээр нь тестийн үр дүнд нөлөөлөх тул тохиргоо буюу тестийн орчны хэсэгт тодорхой заана.

### A2. Хязгаарлалт ба тооцоо

**Алдааны давуу эрэмбэ:** From → To → Amount → Currency conversion. Нэг хүсэлтэд олон алдаа байвал хамгийн түрүүнд шалгагдах алдааг буцаана гэж тестийн oracle-д үзнэ. Энэ эрэмбэ нь өгөгдсөн тодорхойлолтод заагаагүй тул тестийн загварын таамаглал болно.

[ERROR] утгууд нь амжилтгүй үр дүн үүсгэх төлөөлөх утгууд. [SINGLE] хязгаарлалт нь нэг тестэд хамгийн ихдээ нэг алдааны утга оруулах зарчим. [IF] хязгаарлалт нь нөхцөл биелэх үед өөр сонголтын утгыг хязгаарлана.

Эхний бүрэн олонлогийн тоо:

`3 × 3 × 4 × 2 = 72`

**Хязгаарлалтын тэмдэглэгээ ба үндэслэл**

- `[ERROR]`: тухайн утга нь тодорхой алдааны нөхцөлийг төлөөлнө. `From = Frozen`, `From = Missing`, `To = Missing`, `To = SameAsFrom`, `Amount = Zero`, `Amount = OverBalance`, `Amount = OverLimit` нь алдааны утгууд юм.
- `[SINGLE]`: нэг тестийн мөрөнд хамгийн ихдээ нэг алдааны утга байна. Энэ нь алдаа тус бүрийн үр дүнг тусад нь шалгах боломж олгоно.
- `[IF]`: `From = Missing` бол `Amount = Normal`; `To = Missing` бол `Amount = Normal` байна. Данс байхгүй үед дүнгийн өөр алдааг давхар оруулахгүй гэсэн загварын хязгаарлалт юм.

**Хослолын тооцоо**

Эхний бүрэн хослолын тоо:

`N = 3 × 3 × 4 × 2 = 72`

`[IF]` хязгаарлалтыг хэрэглэсний дараа:

- `From = Missing`: `To`-ийн 3 утгаас `Amount = Normal` гэсэн 1 утга, `Currency`-ийн 2 утга боломжтой. `1 × 3 × 1 × 2 = 6`.
- `From = Valid` эсвэл `Frozen`, `To = Missing`: `Amount = Normal` тул `2 × 1 × 1 × 2 = 4`.
- `From = Valid` эсвэл `Frozen`, `To = Valid` эсвэл `SameAsFrom`: дөрвөн `Amount` утга боломжтой. `2 × 2 × 4 × 2 = 32`.

Иймээс `[IF]`-ийн дараах нийт тоо `6 + 4 + 32 = 42`.

`[SINGLE]`-ийг нэмж, нэг мөрөнд зөвхөн нэг алдааны утга зөвшөөрвөл:

- Алдаагүй мөр: `From = Valid`, `To = Valid`, `Amount = Normal`, `Currency = Same/Different` → 2.
- `From`-ийн алдаа (`Frozen`, `Missing`): тус бүрд 2 валют → 4.
- `To`-ийн алдаа (`Missing`, `SameAsFrom`): тус бүрд 2 валют → 4.
- `Amount`-ийн алдаа (`Zero`, `OverBalance`, `OverLimit`): тус бүрд 2 валют → 6.

Тэгэхээр хязгаарлалтуудын дараах тоо `M = 2 + 4 + 4 + 6 = 16`. Нийт боломжит хослол `72 → 42 → 16` болж буурна. Энэ тооцоо нь `[SINGLE]`-ийг бүх параметрийн алдааны утгад хатуу хэрэглэсэн загварын таамаглалд үндэслэнэ.
